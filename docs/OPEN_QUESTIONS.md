# Shortlet Connect V1 — Open Questions & Recommended Defaults (`OPEN_QUESTIONS.md`)

All open items from PRD v1.6 (Section 12) and Master Build Prompt (Section 10) are tracked here behind runtime configuration in `SystemConfig` wherever applicable.

| ID | Topic | Open Question | Recommended Default (Active Behind Config) | Status |
|----|-------|---------------|--------------------------------------------|--------|
| OQ-01 | **Merchant Settlement & Caution Custody** | Confirm Paystack merchant settlement schedule, bank accounts, payout timing, and lawful custody/holding model for refundable caution fees with Paystack and legal/accounting advisers. | Assume **no escrow and no automatic bank split**; track caution deposits strictly as a **liability** ledger category (`caution_deposit_liability`) with manual Super Admin approval and traceable transaction reference on payout/refund. | Pending legal & Paystack confirmation |
| OQ-02 | **Partial Car Rental Multi-Day Cutoffs** | Beyond confirmed 12-hour = 1 unit and 24-hour = 1 unit (and 3 days = 3 units), how should partial multi-day car rentals (e.g., 30 hours or 36 hours) be charged? | Configurable `carPartialDayCutoffHours` in `SystemConfig` (default: any duration `<= 24h` = 1 unit; `> 24h` charges `Math.ceil(hours / 24)` units, with grace cutoff adjustable by Super Admin without code changes). | Configurable via `SystemConfig` |
| OQ-03 | **Cancellation & Refund Tiers** | Exact cancellation notice windows and refund percentages for apartments, cars, and boats. | Placeholder V1 policy published on `/policies` (48h+ notice = full rental refund minus gateway fee; <48h = 50% or agent policy; caution deposit always 100% refunded if cancelled before check-in). | Pending founder sign-off |
| OQ-04 | **Commercial Video Inspection Provider** | Select an external video meeting provider whose commercial terms explicitly permit live property inspections (`meet.ffmuc.net` is reference only). | External meeting URL input field supporting any commercially licensed provider (e.g., Google Workspace Meet, Zoom Pro, or self-hosted Jitsi). | Pending provider selection |
| OQ-05 | **Launch City & Operational SLAs** | Confirm initial launch city/zones, exact partner verification document rubric, operational response SLA targets, and approved admin role roster. | Default launch focus: **Lagos (Victoria Island, Ikoyi, Lekki Phase 1, Banana Island)** with operational admin cap configurable at `10`. | Active default |
| OQ-06 | **WhatsApp Business Platform (BSP) Provider** | Choose official WhatsApp Business API provider (Meta Cloud API, Twilio, 360dialog, or Termii) and confirm template approval & conversation pricing. | Implemented behind `WhatsAppProvider` adapter with sandbox shared-inbox simulator and context-aware `wa.me` deep links using single official business number. | Pending BSP selection |
| OQ-07 | **No-Agent Photo Attribution Rule (`MEDIA-01`)** | What watermark attribution text should appear on published photos when a listing is submitted directly by a verified property owner or platform operator with no agent? | Never invent an agent. Default attribution: **`Listed by: Verified Owner`** (for direct owner submissions) or **`Listed by: Shortlet Connect`** (for platform-managed listings). | Active default |
| OQ-08 | **Identity Document Retention Period (`PART-09`)** | Required retention duration and purge schedule for uploaded partner identity documents (NIN slip, Passport, Driver's Licence, PVC). | Private encrypted storage with configurable `identityDocRetentionDays` in `SystemConfig` (default: **365 days** after account closure/rejection, or immediate purge upon verified request subject to dispute hold). | Configurable via `SystemConfig` |
| OQ-09 | **Video Watermarking: V1 vs V2 (`MEDIA-02` vs `PART-11`)** | Section 9B requests permanent burned-in video watermarking in V1 subject to technical feasibility; PART-11 states it remains V2. | Photo watermarking ships 100% in V1. Video upload & playback ship in V1 behind `MediaProcessor` + `VIDEO_WATERMARK_ENABLED` flag (default `false` in serverless runtime due to FFmpeg CPU/timeout constraints; recommended V2 async Cloud Run/Transcoder worker). | Awaiting client confirmation |
