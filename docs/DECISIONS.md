# Shortlet Connect V1 — Architectural Decisions Log (`DECISIONS.md`)

| ID | Decision | Alternatives Considered | Rationale |
|----|----------|-------------------------|-----------|
| DEC-01 | **Next.js 15 App Router + TypeScript + Tailwind CSS v4** | Separate SPA + Express API | Single deployable full-stack codebase with server-side API routes for Paystack verification, permanent image watermarking (`sharp`), and OTP challenges, while delivering fast mobile-first SSR/CSR discovery. |
| DEC-02 | **Firebase Firestore (Enterprise Edition) + Firebase Auth with Strict Split-Collection Rules** | Cloud SQL PostgreSQL (unavailable in current GCP project) | Provides transactional slot-lock documents (`/availabilitySlots/{listingId}_{slotKey}`) for concurrency-safe double-booking prevention, strict collection-level PII/owner-contact isolation (`/listingOwnerSecrets` Super Admin only), and zero-trust security rules enforced on the server. |
| DEC-03 | **Integer Kobo Monetary Representation (`NGN`)** | Decimal strings / floating point Naira | Eliminates IEEE-754 rounding errors across ₦30,000 service charge units and ₦10,000 / ₦10,000 / ₦10,000 three-way allocations (`1 NGN = 100 kobo`). |
| DEC-04 | **Explicit Response Allow-Lists (`toPublicListing`, `toCustomerBookingView`)** | Deny-list field stripping | Guarantees exact building numbers, legal owner contacts, property manager phones, unprocessed media originals, and internal ₦10k ledger splits can never leak into public or customer payloads even as new private fields are added. |
| DEC-05 | **Server-Side Permanent Photo Watermarking via `sharp` SVG Compositing** | Client-only CSS overlays | Burns `SHORTLET CONNECT` and `Listed by: <Agent>` directly into the output image pixels during server-side processing (`/api/media/watermark` & `/api/media/public/[filename]`), keeping unwatermarked originals in private storage (`private_media/`). |
| DEC-06 | **Video Watermarking behind `MediaProcessor` Adapter & `VIDEO_WATERMARK_ENABLED` Flag** | Unconditional V1 FFmpeg transcoding or dropping video uploads | Resolves the PRD Section 9B vs PART-11 conflict cleanly: video upload/playback works in V1 while permanent burn-in runs asynchronously behind a configurable flag pending final client decision and transcoding budget sign-off. |
| DEC-07 | **Swappable External Service Adapters with Offline Sandbox Mocks** | Direct SDK coupling in routes | `PaymentProvider` (Paystack), `WhatsAppProvider`, `OtpProvider`, and `MediaProcessor` all sit behind clean TypeScript interfaces so every requirement and invariant is 100% testable offline with deterministic tests. |
| DEC-08 | **UTC Storage, `Africa/Lagos` (`WAT`) Display, Half-Open `[check-in, check-out)` Ranges** | Local timezone DB strings / inclusive end dates | Prevents checkout-day/check-in-day false conflicts on back-to-back apartment stays and removes DST/offset ambiguity. |
| DEC-09 | **Removal of Out-of-Scope AI Features (Concierge & AI Photo Studio)** | Keeping AI features behind a flag | Removed completely per Audit Task 1: AI-altered photos undermine marketplace trust and sending listing/customer data to third-party AI services is not approved in the PRDs. |
| DEC-10 | **Strict Client-Write Lockout on Privileged Firestore Collections (Local Rules Held)** | Role-gated client SDK writes | Hardened local `firestore.rules` denies all client writes to 15 privileged collections, enforces `isActiveUser()`, and locks `channelVerified == false`. Verified 8/8 suites against local Firestore Emulator; kept local (NOT deployed) per user instruction because `gen-lang-client-0828454544` is an AI Studio Starter Tier project. |
| DEC-11 | **Deterministic Per-Unit Slot Documents for Firestore Double-Booking Protection** | Query-before-write range scans (race-prone in Firestore) | Firestore transactions cannot lock arbitrary range queries, so `FirestoreAvailabilityRepository` creates deterministic per-unit slot documents (`apt_{id}_{YYYY-MM-DD}`, `boat_{id}_{YYYY-MM-DD}_B{00..11}`, `car_{id}_{YYYY-MM-DD}_H{00..23}`) inside `runTransaction`. Verified with 20-way parallel emulator tests; maps cleanly to PostgreSQL `EXCLUDE USING gist` in `docs/POSTGRES_MIGRATION.md`. |
| DEC-12 | **Portable `RepositoryBundle` Isolation (`lib/repositories/`)** | Direct Firestore calls inside UI & API routes | All API routes and UI providers read/write through `lib/repositories/` so zero components/pages/routes import `firebase/firestore` directly. Enables zero-rewrite swap from Firestore MVP to Supabase/PostgreSQL. |
| DEC-13 | **RFC 6238 TOTP Super Admin MFA + Signed Revocable `HttpOnly` Sessions** | Client-side localStorage tokens or Firebase-only sessions | Super Admin routes enforce TOTP second-factor (`requireSuperAdminWithMfa`), customer OTP access issues short-lived `HttpOnly; Secure; SameSite=None; Partitioned` cookies, and account suspension immediately revokes all active server sessions. |
| DEC-14 | **AES-256-GCM Encrypted Private Storage for Partner Identity Documents** | Plaintext local files or public storage URLs | Partner NIN/Passport/Licence/PVC uploads are magic-byte validated, encrypted with AES-256-GCM outside `public/`, served solely via MFA-verified Super Admin proxy (`/api/identity-docs/[docId]`), and purged via scheduled retention job (`/api/identity-docs/purge`). |
