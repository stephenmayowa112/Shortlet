# Shortlet Connect V1 — Architectural Decisions Log (`DECISIONS.md`)

| ID | Decision | Alternatives Considered | Rationale |
|----|----------|-------------------------|-----------|
| DEC-01 | **Next.js 15 App Router + TypeScript + Tailwind CSS v4** | Separate SPA + Express API | Single deployable full-stack codebase with server-side API routes for Paystack verification, permanent image watermarking (`sharp`), OTP challenges, and Gemini Concierge, while delivering fast mobile-first SSR/CSR discovery. |
| DEC-02 | **Firebase Firestore (Enterprise Edition) + Firebase Auth with Strict Split-Collection Rules** | Cloud SQL PostgreSQL (unavailable in current GCP project) | Provides transactional slot-lock documents (`/availabilitySlots/{listingId}_{slotKey}`) for concurrency-safe double-booking prevention, strict collection-level PII/owner-contact isolation (`/listingOwnerSecrets` Super Admin only), and zero-trust security rules enforced on the server. |
| DEC-03 | **Integer Kobo Monetary Representation (`NGN`)** | Decimal strings / floating point Naira | Eliminates IEEE-754 rounding errors across ₦30,000 service charge units and ₦10,000 / ₦10,000 / ₦10,000 three-way allocations (`1 NGN = 100 kobo`). |
| DEC-04 | **Explicit Response Allow-Lists (`toPublicListing`, `toCustomerBookingView`)** | Deny-list field stripping | Guarantees exact building numbers, legal owner contacts, property manager phones, unprocessed media originals, and internal ₦10k ledger splits can never leak into public or customer payloads even as new private fields are added. |
| DEC-05 | **Server-Side Permanent Photo Watermarking via `sharp` SVG Compositing** | Client-only CSS overlays | Burns `SHORTLET CONNECT` and `Listed by: <Agent>` directly into the output image pixels during server-side processing (`/api/media/watermark` & `/api/media/public/[filename]`), keeping unwatermarked originals in private storage (`private_media/`). |
| DEC-06 | **Video Watermarking behind `MediaProcessor` Adapter & `VIDEO_WATERMARK_ENABLED` Flag** | Unconditional V1 FFmpeg transcoding or dropping video uploads | Resolves the PRD Section 9B vs PART-11 conflict cleanly: video upload/playback works in V1 while permanent burn-in runs asynchronously behind a configurable flag pending final client decision and transcoding budget sign-off. |
| DEC-07 | **Swappable External Service Adapters with Offline Sandbox Mocks** | Direct SDK coupling in routes | `PaymentProvider` (Paystack), `WhatsAppProvider`, `OtpProvider`, and `MediaProcessor` all sit behind clean TypeScript interfaces so every requirement and invariant is 100% testable offline with deterministic tests. |
| DEC-08 | **UTC Storage, `Africa/Lagos` (`WAT`) Display, Half-Open `[check-in, check-out)` Ranges** | Local timezone DB strings / inclusive end dates | Prevents checkout-day/check-in-day false conflicts on back-to-back apartment stays and removes DST/offset ambiguity. |
